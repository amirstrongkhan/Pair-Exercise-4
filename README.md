# IST 303 Pair Exercise #4

**Partners** — Diego Estuar and Amir Khan

[`pe4.py`](pe4.py) compares sequential and threaded downloads of Wikipedia references for topics related to “generative artificial intelligence.”

With a Python virtual environment active, run these commands from the repository directory.

```sh
python -m pip install wikipedia
python pe4.py
```

The script prints the elapsed time for each pass and writes one reference URL per line to files named for the page titles. Both passes write to the current directory.
